# Unused generated asset archive

These are original generated Agent Fleet Audit variants that were superseded during visual refinement. They are retained for provenance and future exploration, not loaded by the application.

- `legacy/`: 10 early PNG/WebP concepts and atlases.
- `reference-clone/`: the superseded architecture-mosaic AVIF/WebP pair.
- `visual-expansion/`: three superseded architectural brand-world AVIF/WebP pairs.

The archive contains 18 raster files. Before restoring one, move or copy it into an active asset family, provide AVIF and WebP variants, update the application reference, and update [`../../../../../docs/ASSET_INVENTORY.md`](../../../../../docs/ASSET_INVENTORY.md) and [`../../../../../DESIGN.md`](../../../../../DESIGN.md).
