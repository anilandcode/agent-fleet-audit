# Agent Fleet Audit visual asset brief

This folder contains the original generated raster artwork used to support the graphite, olive, ivory, and champagne interface. Artwork is concept imagery—not rasterized product UI—and contains no logos, readable copy, customer marks, or provider branding.

## Folder structure

- `reference-clone/`: active monochrome ownership/failure scenes.
- `visual-correction/`: active capability, architecture, AI concept, transition, and demo-state visuals.
- `visual-expansion/`: active hero, editorial, and institutional-memory visuals.
- `archive/unused/`: retained generated variants that are no longer referenced.
- `../../../Images/`: user-supplied inspiration screenshots, kept separate and never served by the application.

## Shared generation direction

Original cinematic enterprise editorial art; charcoal, graphite, muted olive, champagne, and ivory; refined texture and restrained bloom. Avoid literal dashboard screenshots, generic circuits, neon cyberpunk, saturated blue/purple, readable text, third-party branding, recognizable proprietary artwork, and unsupported client marks.

Interface labels, system traces, the brand mark, and diagrams remain code-native HTML/SVG. Active raster assets are delivered as AVIF with WebP fallback. The complete used/unused/provenance ledger is maintained in `docs/ASSET_INVENTORY.md`.
